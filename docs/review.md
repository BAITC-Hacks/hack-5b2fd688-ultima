# Повторная сверка с ТЗ и датасетом

Проверены исходные документы «HackAlem AI — Аким на 5 часов» и «Датасет районов», backend, интерфейс, экспорт и документация. Backend дополнительно проверен независимым агентом.

## Математическая модель

С источником совпадают все 50 исходных показателей, доли населения пяти районов, десять весов, а также стоимость, тип, лаг и эффекты всех 14 мер. Подтверждены три синергии, три несовместимости, бюджет 100, ровно пять уникальных решений и максимум два решения на направление.

Формула: `Score = 0.7 × D_avg + 0.3 × min(D_d) − N_crit`. Эффект масштабируется по лагу, синергия добавляется без масштабирования, ограничение 0–100 применяется после суммирования. Критический порог — строго `<40`.

| Контроль | Бюджет | Score |
|---|---:|---:|
| Исходный город | — | 52.55768 → **52.56** |
| M7 Нура + M8 Нура + M10 Нура + M12 город + M5 Сарыарка | 95 | 56.54307 → **56.54** |
| Замена M5 на M3 в Нуре | 100 | 57.20556 → **57.21** |

Независимая проверка на Decimal рассмотрела 2000 сценариев: 800 допустимых пересчитаны без расхождений, 1200 недопустимых отклонены. Это выборочная проверка, а не полный перебор всех планов.

## Исправленные дефекты

- Обрыв HTTP-ответа провайдера больше не приводит к потере отчёта: возвращается объяснение по правилам с корректным Score.
- AI выбирает выводы по ID из серверного каталога фактов. Проверяются существование ID, допустимость раздела, количество пунктов, повторы и точный набор полей. Произвольный текст провайдера не отображается; у каждого утверждения доступны расчётные основания.
- Имена команд нормализуются до проверки; управляющие символы, некорректный Unicode и неверные коды отклоняются с 422. Проверки одинаковы для API и прямого вызова хранилища.
- Локальный разбор различает смену слабейшего района и сохранение его статуса; неизменившийся балл не описывается как изменение.
- Прямой валидатор отклоняет неверный тип района без исключения `TypeError`.
- Определения шкалы всех показателей восстановлены дословно из датасета.
- В экспорт включены последствия из подготовленного анализа. Объём текста слайда ограничен явно обозначенными выдержками; длинный разбор печатается на трёх страницах.

## Интерфейс

Обновлены навигация, обзор города, карточки районов, каталог инициатив, закреплённый план, результаты и мобильная панель. Все исходные показатели доступны до выбора решений по клику на район. В карточках мер показаны названия показателей и реализованный эффект; в результатах — источники изменений.

Добавлены раскрываемая декомпозиция Score, загрузка контрольного примера с обоснованием и личное сравнение А/Б. Снимок А сохраняет только ID решений и версию модели; после перезагрузки сервер пересчитывает его без обращения к AI. Сравнение показывает выигрыш и потери относительно плана А, включая отказ от улучшений в других районах.

## Подтверждение настоящего LLM

После настройки серверного ключа выполнена живая проверка через интерфейс и `/api/analyze`. Провайдер — OpenAI, модель — `gpt-4.1-mini`, формат — Structured Outputs с JSON-схемой разрешённых ID. Контрольный план и его альтернатива вернули `explanation.source="openai"`, `status="ok"`, `grounding="verified_fact_selection"`: Score `56.54307` при расходах `95` и `57.20556` при расходах `100`. Интерфейс показал метку «ИИ-РАЗБОР»; все пять разделов совпали с каноническими утверждениями из `evidence`. В этом прохождении ответы получены примерно за три секунды. Проверены также декомпозиция, сравнение А/Б и трёхстраничный PDF живого отчёта.

Первичные ответы со свободным текстом выявили неподтверждённые общие рассуждения. Поэтому интеграция переведена на выбор канонических фактов: LLM ранжирует и распределяет проверенные утверждения по разделам, а сервер собирает объяснение из их формулировок и числовых оснований. Даже допустимый существующий ID нельзя использовать в неподходящем разделе.

Выбор приоритетов AI может отличаться между запросами. Числа, формулировки и основания выводов берутся из расчёта одного и того же сценария; неизвестный факт или нарушение контракта возвращает локальный разбор из того же каталога.
