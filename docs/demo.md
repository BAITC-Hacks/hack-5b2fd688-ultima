# Демонстрация жюри

## Сценарий показа

1. Открыть симулятор и показать общий стартовый Score `52,56`, бюджет `100`, баллы пяти районов. Нажать карточку Нуры в блоке «Один город. Разные приоритеты.»: в раскрытом профиле S1 = 38 и S2 = 35, оба ниже 40. Переключить район, чтобы показать другие исходные показатели. Данные синтетические и единые для всех.
2. Показать отказ без Score: выбрать M3 в Есиле, M5 в Сарыарке, M7 и M8 в Нуре (расход 99). Попробовать добавить M10 в Байконуре — сервер отклонит превышение бюджета на 11 единиц, пятая мера не добавится. Затем нажать «Сбросить».
3. Нажать «Загрузить пример»: M7 и M8 в Нуре, M10 в Нуре, M12 для города, M5 в Сарыарке. Показать краткое обоснование выбора. Каталог показывает эффекты **с учётом лага**, например M7: S1 +10.
4. По ходу выбора показать обновление бюджета и выбор района для районной меры. Для расчёта нужны ровно пять разных мероприятий; допустимо до двух из одного направления.
5. Нажать «Рассчитать сценарий». Показать итог `56,54` (`+3,98` по разнице отображаемых Score; точная дельта `+3,98539`), расходы `95`, остаток `5` и ноль показателей ниже порога 40.
6. Раскрыть «Как получился Score?» — показать вклад среднего уровня, слабейшего района и снятие штрафа. Затем раскрыть показатели Нуры и Сарыарки; показать городское действие M12, которое меняет обращения во всех районах.
7. Показать синергию M10 + M12. При рабочем ключе проверить метку «ИИ-РАЗБОР» и раскрыть «Основание расчёта» у вывода. AI выбирает акценты из проверенных фактов; значения и формулировки подставляет сервер. Без ключа источник помечен «ПО ДАННЫМ МОДЕЛИ».
8. Показать варианты улучшения: каждый кандидат меняет одну меру или её район, проходит валидацию и получает Score из того же движка.
9. Нажать «Сохранить для сравнения», затем заменить M5 в Сарыарке на M3 в Нуре и рассчитать снова: расходы `100`, Score `57,21`, улучшение показанных баллов `+0,67` к плану А. Открыть сравнение «План А / План Б»: выигрыш транспорта Нуры сопровождается потерей эффектов M5 для воздуха и ЖКХ Сарыарки; это проверенный компромисс, а не глобальный оптимум.
10. Сохранить сценарий под названием команды, показать таблицу результатов и сравнение баллов районов с другим планом. Для изменения своей записи с другого устройства нужен выданный код команды.
11. Нажать «Презентация / PDF»: открыть загруженный HTML-файл, пролистать три слайда и при необходимости распечатать в PDF.

## Ограничения для рассказа

- Датасет синтетический: результат демонстрирует логику модели, а не официальный прогноз или описание фактического положения районов.
- Числа считает детерминированное ядро. AI объясняет рассчитанные значения и не подменяет Score.
- Остаток бюджета сам по себе не даёт бонуса.
