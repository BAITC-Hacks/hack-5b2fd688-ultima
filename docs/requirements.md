# Соответствие техническому заданию

Ориентир — предоставленные документы «Аким на 5 часов» и «Датасет районов». Данные и математическая формула синтетические; это инструмент объяснения управленческих компромиссов, а не статистический прогноз для настоящей Астаны.

## Обязательные требования

| Пункт задания | Реализация | Как проверить |
|---|---|---|
| Единый бюджет и исходные данные | `backend/data/simulation.json`, `backend/app/engine.py`, блок «Районы до ваших решений» | `GET /api/config`: бюджет 100; на экране до выбора видны баллы, профили и десять показателей каждого района |
| Ровно пять решений по заданным направлениям | Каталог и валидатор `backend/app/engine.py` | Выберите пять мер из пяти направлений каталога; не более двух из одного направления. Следовательно, можно выбрать 3–5 направлений — это точные правила датасета. |
| Контроль бюджета | `/api/validate`, `/api/simulate`, интерфейс | Попробуйте добавить меру сверх 100: выбор не меняется и выводится причина; API не даёт Score невалидному набору |
| Итоговый Astana Quality of Life Score | Формула в `backend/app/engine.py` | База 52,56; контрольный пример 56,54 |
| AI-анализ | `backend/app/ai.py` с серверным OpenAI API | Для подтверждения требования нужен реальный вызов с ключом: `source="openai"`. Без ключа или при ошибке — честно обозначенное локальное объяснение `source="rules"`, а не LLM. Score всегда рассчитывает код. |
| Сильные стороны, риски, возможные последствия | `explanation` в `/api/analyze`; блок результата в `web/index.html` | Выбрать пять мер и открыть раздел «Разбор сценария» |

## Дополнительные возможности

| Пункт задания | Реализация / ограничение |
|---|---|
| Сравнение результатов нескольких команд | Общая SQLite-база на одном сервере; API `/api/leaderboard`, рейтинг текущей версии модели, просмотр решений и районных баллов. Код команды нужен для обновления своей записи. |
| Визуализация районов | Баллы до/после, таблица изменённых и оставшихся критических показателей; синергии показаны отдельно. |
| AI-рекомендации | До трёх допустимых замен ищет scoring engine (`backend/app/recommender.py`), AI объясняет проверенные варианты. Локальный поиск по одной замене не гарантирует глобальный оптимум. |
| Генерация краткой презентации | `web/presentation.js`: три автономных слайда с печатью в PDF. |
| Неожиданные городские события | Пока не включены в каноническую модель: в предоставленном датасете нет численных параметров событий. Для расширения нужен отдельный, явно помеченный стресс-сценарий с новыми предположениями, чтобы не менять общий старт команд. |

## Проверяемость

Движок и API проверяются `python -m pytest -q`. Сквозной сценарий в Chromium: `python scripts/e2e_smoke.py`. Исходный и контрольный Score, порядок решений, строгий порог `<40`, лаг, синергии, несовместимости, отказ при превышении бюджета, сравнение разных команд и отсутствие подмены чисел текстом AI зафиксированы тестами.
